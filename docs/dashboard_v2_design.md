# Dashboard OS Ver.2 設計書

## 1. 設計思想

このダッシュボードは、毎日の生活・発信・思考を無理なく回すための個人OSとして設計する。

最優先するのは「毎日使えること」。  
多機能さよりも、開いた瞬間に今日やることが見えること、入力が重くないこと、同じ情報を何度も書かなくて済むことを重視する。

### 基本方針

- 毎日使うことを最優先する
- 入力項目は最小限にする
- 同じ情報を二重入力しない
- ホームは「今日を始める場所」にする
- 各ページは独立して完結させる
- 必要になったらページを増築する
- 最初から作りすぎない
- デザインより使いやすさを優先する
- 設計書にない項目を実装中に勝手に追加しない

## 3. 各ページ詳細

## ホーム

ホームは、このOSの起点。  
朝に開いて「今日をどう始めるか」を決め、必要なページへ移動するための場所にする。

### 項目

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 今日の始まり | 今日の日付、開始時刻、ひとこと | 今日の開始を記録できる |
| 睡眠 | 合計睡眠時間、睡眠回数、最長睡眠時間、一言 | ライフ > 睡眠と情報を共有し、二重入力しない |
| 今日できること | 表情、気分、読む、書く（新規記事）、コメント・交流、掃除・家事、実装・開発 | ○・△・×を中心にワンタップで選べる |
| 今日の用事 | 今日ある予定・外せない用事 | 短く入力できる |
| タスク | 今日やること | チェックできる。増やしすぎない |
| メール | 確認が必要なメール | 未確認・対応済みを分けられる |
| DM | 確認が必要なDM | 未確認・対応済みを分けられる |
| 10時以降モード | Seed、読書、Brain、生活、発信 | 複数選択でき、日付別データとして保存される。翌日は未選択に戻る |
| 各ページへの入口 | 発信・思考・ライフへのリンク | ホームから迷わず移動できる |

### ホームでやらないこと

- 発信記事の詳細管理
- 読書メモの長文入力
- 睡眠ログの詳細分析
- 複雑なタスク管理

ホームはあくまで「今日を始める場所」とし、詳細は各ページに任せる。

## 発信

発信ページは、複数媒体の投稿状況を一か所で見渡す場所。  
媒体ごとに役割が違うため、Substack、note、X、WordPressを分けて管理する。

### Substack

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 昨日の振り返り | 記事タイトル、公開したか | 前日のSubstack活動を短く保存できる |
| 反応 | 引用リスタック、新規購読者、総フォロワー数 | 数字を日付別に残せる |
| やったこと | 記事、Notes、コメント、おはスタック！、ライブ | チェックボックスで複数選択できる |
| 気づき | 一言だけ | 長文にせず一言で保存できる |
| 今日 | 今日の記事テーマ、今日やること、今日試したいこと | 今日の発信方針を保存できる |
| ストック | 記事ネタ、Notesネタ、Seed | 先のネタを軽く置いておける |

### note 1: AI × 生活・回復

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 昨日の振り返り | 記事タイトル、公開したか、ビュー、スキ、気づき | 前日のnote①を日付別に短く保存できる |
| 今日 | 今日の記事テーマ、今日やること | 今日書く方向を保存できる |
| ストック | 記事ネタ、SEO化待ち | AI×生活・回復のネタを置いておける |

### note 2: Substack初心者向け

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 昨日の振り返り | 記事タイトル、公開したか、ビュー、スキ、気づき | 前日のnote②を日付別に短く保存できる |
| 今日 | 今日の記事テーマ、今日やること | 今日書く方向を保存できる |
| ストック | 記事ネタ、よくある質問 | Substack初心者向けのネタを置いておける |

### X

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 昨日の振り返り | 投稿①、投稿②、投稿③ | 前日の投稿内容を3件まで保存できる |
| 反応 | インプレッション、いいね、エンゲージメント、詳細クリック、プロフィールアクセス、フォロワー数 | 主要な反応数値を日付別に保存できる |
| 気づき | 一言 | 長文にせず一言で保存できる |
| 今日 | 投稿①、投稿②、投稿③、今日やること | 今日の投稿内容と作業を保存できる |
| ストック | 投稿ネタ①、投稿ネタ②、投稿ネタ③ | 投稿候補を3件まで置いておける |

### WordPress

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 昨日の振り返り | 記事タイトル、公開したか | 前日のWordPress記事を日付別に保存できる |
| 気づき | 一言 | 長文にせず一言で保存できる |
| 今日 | 新しい記事、今日書く記事、固定ページ、今日進めるページ、今日やること | 今日進める記事・固定ページを保存できる |
| ストック | 新しい記事、記事ネタ、固定ページ、改善アイデア | WordPressの次候補を置いておける |

## 思考

思考ページは、まだ形になっていない考えを置く場所。  
発信やタスクにすぐ変換しなくてもよい。Seed、読書、メモを分けて扱う。

### Seed

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 種 | 思いついた考え、違和感、問い | 短く保存できる |
| 分類 | 発信候補、生活、仕事、学びなど | 後から探しやすくする |
| 状態 | 未整理、育てる、発信へ | 考えの成長段階を見える化する |
| 次の一歩 | 調べる、書く、寝かせる | 思考を止めずに置いておける |

### 読書

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 本の情報 | 書名、著者 | 読書記録を残せる |
| 読書メモ | 印象に残った内容、引用、考え | 長すぎないメモとして保存できる |
| 状態 | 読みたい、読書中、読了 | 読書状況を管理できる |
| 発信候補 | 記事や投稿に使えそうな点 | 発信ページへつなげられる |

### メモ

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| メモ本文 | その場で残したいこと | すぐ書ける |
| タグ | 任意の分類 | 後から探せる |
| 状態 | 未整理、保存、発信候補 | メモの扱いを決められる |
| 関連先 | 発信、Seed、読書など | 必要に応じて別ページへつなげられる |

## ライフ

ライフページは、生活の土台を記録する場所。  
最初は睡眠だけを扱い、必要になったら項目を増やす。

### 睡眠

| 項目 | 入力内容 | 必要な機能 |
|---|---|---|
| 就寝時刻 | 寝た時間 | 睡眠ログとして保存できる |
| 起床時刻 | 起きた時間 | 睡眠時間を計算できる |
| 睡眠時間 | 自動計算または手入力 | ホームにも反映する |
| 睡眠の質 | ○・△・×、または短い選択肢 | 朝の状態とつなげられる |
| メモ | 眠れなかった理由、起床時の感覚など | 必要な時だけ書ける |

## 4. ホーム詳細設計

ホームは「今日を始める場所」として、朝に必要な判断だけに絞る。

### 今日の始まり

- 今日の日付を表示する
- 開始時刻を記録する
- 今日のひとことを入力できる

### 睡眠

ホームの睡眠欄は、以前作成した体調チェック項目を再利用する。
入力先を増やさず、既存の `healthState` を更新する。

当初の睡眠要約としては、既存の `healthState` から以下の4項目を表示できる。

- 合計睡眠時間
- 睡眠回数
- 最長睡眠時間
- 一言

既存データとの対応:

- 合計睡眠時間: `sleepHours`
- 睡眠回数: `sleepCount`
- 最長睡眠時間: `longestSleepMinutes`
- 一言: `bodyNote`

詳細入力はライフ > 睡眠で扱う。  
ホームとライフで二重入力しない。

### 今日できること

既存の `capacityCheck` を再利用する。

表示する項目:

- 表情
- 気分
- 読む
- 書く（新規記事）
- コメント・交流
- 掃除・家事
- 実装・開発

Seed、読書、メモは独立ページにするため、この○△×には含めない。

選択肢は細かくしすぎない。  
今日の動き方を決めるための最小限の入力にする。

### 今日の用事

- 今日外せない用事を短く書く
- 予定の詳細管理はしない
- ホームでは「今日それがある」とわかればよい

### タスク

- 今日やることだけを表示する
- チェックできる
- 多すぎるタスクを前提にしない

### メール

- 確認が必要なメールを置く
- 対応済みにできる
- メール本文の詳細管理はしない

### DM

- 確認が必要なDMを置く
- 対応済みにできる
- DM本文の詳細管理はしない

### 10時以降モード

朝の立ち上がりが終わった後に、作業モードへ切り替えるための領域。

候補:

- Seed
- 読書
- Brain
- 生活
- 発信

チェックボックス形式で複数選択できる。  
日付別データとして保存し、翌日は未選択状態に戻る。
表示は横並びを基本とし、項目名が縦書きに見えないようにする。

### 各ページへの入口

ホームには以下の入口を置く。

- Substack
- note（いつものnote）
- note（Substack初心者向け）
- X
- WordPress
- Seed
- 読書
- メモ

入口は大きく、迷わず押せる形にする。
現時点では詳細ページを実装せず、入口と表示切替の土台だけ用意する。

## 5. 実装ルール

Codexで実装する時は、以下のルールを優先する。

### 基本ルール

- 今のダッシュボードをベースに Ver.2 としてリファクタリングする
- デザインより使いやすさを優先する
- 1ページずつ実装する
- 既存機能は活かせるものを活かす
- 設計書を優先する
- 実装中に勝手な項目追加をしない
- 最初から全ページを作り込みすぎない
- ホームを先に作る
- 各ページは単体で使える状態にする

### 実装順

1. ホーム
2. ライフ > 睡眠
3. 発信
4. 思考
5. 必要に応じた追加ページ

### UI方針

- 朝に開いて迷わない画面にする
- 入力欄は少なくする
- 選択式で済むものは選択式にする
- 長文入力をホームに置かない
- チェック、状態変更、ページ移動をすぐできるようにする
- 各ページの役割を混ぜない

### データ方針

- 同じ情報を複数ページで重複保存しない
- ホームは必要な情報を参照・要約する
- 詳細データは各ページに持たせる
- 後から項目追加しやすい形にする
